# Инструкции для Codex

Работа продолжается по правилам Claude Code, без второго набора требований.

Перед изменениями прочитай `CLAUDE.md`, текущий этап в `docs/stages.md`, последние
решения в `docs/handoff.md` и соответствующие разделы `docs/api-contract.md`.
Решения владельца в handoff уточняют старые примеры прототипа.

Применяй инструкции соответствующей роли из `.claude/agents/`:

- `backend-developer.md` — `backend/`, `supabase/`, контракт API.
- `frontend-developer.md` — `frontend/`.
- `designer.md` — `design/`.
- `tester.md` — `tests/`, `docs/bugs.md`.

Основной агент координирует роли и ведёт передачу. При последовательной работе
применяет правила роли для текущей задачи; при делегировании сохраняет границы
владения каталогами. Поле `model: sonnet` — настройка Claude Code, не требование
к модели Codex.

Не откатывай незакоммиченные изменения предыдущего агента. Сначала установи
фактическое состояние по коду и проверкам: старые записи handoff могут отставать.
Не объявляй этап закрытым по одним unit-тестам. Отдельно отмечай проверенные
локально сценарии, проверки Postgres/RLS и выкатку.

Деньги — целые копейки, округление только в `backend/engine/money.py`.
Frontend только отображает расчёты backend. Golden-ожидания не подгоняются
под реализацию. Интерфейс и документация — по-русски.
