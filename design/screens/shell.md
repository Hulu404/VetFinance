# Оболочка кабинета (shell)

Рамка вокруг всех экранов после входа: боковое меню, шапка страницы, область содержимого. Источник: v6 `.app`, `.sidebar`, `.nav`, `.sfoot`, `.main`, `.head` (функции `drawNav`, `head`). Токены: `design/tokens.css`. Значки: `design/icons.svg`.

Без ролей, без филиалов, без бота. Раздела «Врачи» (функция 16) в меню нет.

## Структура

```
┌───────────┬──────────────────────────────────────────┐
│ ▮ ВетФинанс│  Рабочий стол                    [слот]   │  шапка страницы
│ Клиника   │  9 сентября 2026 · данные обновлены 04:12 │
│           │                                           │
│ Рабочий…  │  содержимое экрана                        │
│ Транзакц… │                                           │
│ …         │                                           │
│           │                                           │
│ (Е) почта │                                           │
│   Выйти   │                                           │
└───────────┴──────────────────────────────────────────┘
```

Разметка: `<a class="skip-link">` «Перейти к содержимому» (первым в DOM, виден только при фокусе), `<aside>` с `<nav aria-label="Основное меню">`, `<main id="content" tabindex="-1">`. При смене страницы фокус переходит на `<h1>` страницы, заголовок документа (`<title>`) меняется на «Название экрана · ВетФинанс».

## Боковое меню

Ширина `--sidebar-width` (252px), фон `--color-sidebar`, внутренние отступы 20px 13px, зазор между блоками 16px; липкое (`position: sticky; top: 0; height: 100vh`), при нехватке высоты скролл без полосы. Класс `.on-dark` на контейнере включает белую рамку фокуса.

### Бренд

Метка 40×40px, радиус `--radius-md`, фон `--color-accent-faint`, внутри `ic-logo` бордовым 24px (v6 `.brand-mark`). Рядом «ВетФинанс» (18px, 800) и под ним название клиники (11px, `--color-on-dark-meta`).

| Данные | Источник |
| --- | --- |
| Название клиники | `GET /v1/clinic` → `name` |

Состояния: загрузка, под названием продукта серый блок 110×11px; ошибка или пустое название, второй строки нет (остаётся «ВетФинанс»); длинное название обрезается одной строкой с многоточием, полное в `title`. Бренд не ссылка (в v6 тоже), клик ни к чему не ведёт; допустимо ссылкой на Рабочий стол, решение за frontend.

### Пункты меню

Пункт: значок 19px слева, текст 13,5px, 600, высота не меньше 40px (на мобильном 44), радиус `--radius-md`, зазор между значком и текстом 11px (v6 `.nav button`). Цвет по иерархии: `--color-on-dark-nav`; наведение фон `--color-on-dark-hover` + белый текст; активный фон `--color-on-dark-active` + белый текст; `aria-current="page"` на активном. Между группами разделитель 1px `--color-on-dark-line`.

Меню описывается данными (`status`), чтобы открывать разделы по этапам одной правкой:

| --- | --- | --- | --- | --- |
| Рабочий стол | `ic-home` | `/` | **готов** | 0 |
| Транзакции | `ic-tx` | `/transactions` | скоро | 1 |
| Прайс услуг | `ic-price` | `/price` | скоро | 5 |
| (разделитель) | | | | |
| Отчёты | `ic-report` | группа | скоро | 3 |
| ‣ Прибыль и убытки | | `/reports/pnl` | | 3 |
| ‣ Норма | | `/reports/norm` | | 3 |
| ‣ Склад и сроки | | `/reports/stock` | | 3 |
| Планирование | `ic-plan` | группа | скоро | 4 |
| ‣ Платёжный календарь | | `/planning/calendar` | | 4 |
| ‣ Обязательства | | `/planning/obligations` | | 4 |
| Аналитика | `ic-anal` | группа | скоро | 5–6 |
| ‣ Финмодель и прогноз | | `/analytics/forecast` | | 6 |
| ‣ Эффективность клиники | | `/analytics/efficiency` | | 5 |
| (разделитель) | | | | |
| Настройки | `ic-set` | `/settings` | скоро | 1 |

Пути ориентировочные, окончательно за frontend (роутер). Порядок и названия не менять.

**Решение: показываем разделы будущих этапов с пометкой «Скоро»**, а не скрываем. Причины: клиника видит, что получит; структура меню не прыгает от этапа к этапу; в v6 меню целиком. Если партнёр или владелец продукта предпочтёт скрывать, меняется одно поле `status: 'hidden'`.

Пункт со статусом «скоро»:

- Текст `--color-on-dark-meta` (5,4:1, читается), справа плашка `on-dark` «Скоро».
- Не нажимается: `<button disabled>` (скринридер видит пункт и «недоступно»), в порядок табуляции не входит, курсор обычный, наведение без подсветки.
- Группа, у которой все дочерние «скоро», показывается одной строкой с плашкой «Скоро», без стрелки и без раскрытия. Как только у группы появляется готовый дочерний пункт, она раскрывается как в v6.
- Если пользователь введёт адрес «скоро»-раздела вручную, открывается заглушка: заголовок раздела, текст «Этот раздел откроем позже. Сейчас доступен Рабочий стол.» и кнопка «На Рабочий стол».

Группы с готовыми разделами (как в v6): строка со стрелкой `▸` справа, поворачивается на 90° при раскрытии (`--dur-base`); подпункты показываются под группой у активной группы, отступ слева 43px, 13px, 500. Кнопка группы `aria-expanded`.

### Низ меню: пользователь

Блок `.sfoot`: фон белый 5%, радиус `--radius-lg`, отступы 11px 12px.

| Часть | Что | Источник |
| --- | --- | --- |
| Аватар | Кружок 32px, фон `--color-accent`, первая буква почты заглавной, белый 13px 700 | Supabase-сессия: `user.email` |
| Строка 1 | Почта, 13px, 600, обрезка многоточием | то же |
| Строка 2 | Кнопка-ссылка «Выйти», 12px, `--color-on-dark-meta`, при наведении белая; высота нажатия 40px | действие `signOut` |

Роль («владелец клиники» в v6) не показываем: ролей нет. Имя человека не показываем: в контракте нет поля, берём почту (вопрос партнёру и backend в `docs/handoff.md`). «Выйти» в v6 отсутствует, добавлено, без него в кабинете нельзя сменить пользователя.

## Шапка страницы

Блок `.head` над содержимым каждого экрана. Левая часть: `<h1>` 26px, 800 (`--fs-h1`) и под ним строка пояснения 13,5px (`--fs-sm`, `--color-ink-soft`), отступ 3px. Правая часть: слот действий экрана (кнопки, переключатели). Нижний отступ 20px.

Строка пояснения несёт актуальность данных, а не рекламу:

| Экран | Пояснение |
| --- | --- |
| Рабочий стол | «9 сентября 2026 · данные обновлены в 04:12» (поля `as_of`, `data_as_of` из `/v1/dashboard`) |

**Баланс в шапке.** В v6 в правом верхнем углу каждого экрана показан общий баланс (`.bal`, «на счетах и в кассе»). Показывается на всех экранах, кроме Рабочего стола, где то же число уже есть в первой карточке; число раскрывается `FigureTip` из `balance.total`. На этапе 0 других готовых экранов нет, поэтому баланс в шапке появится с этапа 1 (когда появятся Транзакции). Данные берутся из того же запроса `GET /v1/dashboard`, дополнительных запросов нет.

Не показываем в шапке на этапе 0: переключатель периода, кнопки действий.

## Область содержимого

`.main`: отступы `--content-padding`, максимальная ширина `--content-max` (1280px, включая отступы), `min-width: 0`. Экран появляется анимацией `vf-view-in` (`--dur-slow`), при смене страницы прокрутка наверх.

## Адаптив

| Ширина | Раскладка |
| --- | --- |
| 1280 | Меню слева 252px, содержимое справа, отступы 24px 34px |
| 820 (и всё до 820 включительно) | Меню превращается в верхнюю панель на всю ширину. Содержимое под ней, отступы 18px 14px |
| 390 | То же, что на 820; заголовок 26px помещается («Рабочий стол»), числа 22px |

Верхняя панель (до 820px), статичная (не прилипает: она занимает много высоты):

1. Первая строка: метка бренда (36px) + название, справа кнопка «Выйти» (высота 44px). Строка с почтой и аватар не показываются.
2. Вторая строка: пункты меню в горизонтальную ленту с прокруткой (`overflow-x: auto`, `scroll-snap`, полоса скрыта), каждый пункт высотой 44px, значок + текст в одну строку, не сжимается. «Скоро» пункты в ленте остаются, плашка «Скоро» сокращается до 11px без отступов.
3. Третья строка, только если выбранная группа имеет подпункты: подпункты второй лентой. **В v6 подпункты на узком экране скрыты (`.nav .sub{display:none}`), и до всех, кроме первого, нельзя добраться; здесь это исправлено.**

Правка нужна вне этапа 0, когда появятся первые группы, но структура панели закладывается сейчас.

## Состояния оболочки

| Состояние | Что |
| --- | --- |
| Проверка сессии | Пустой экран цвета `--color-bg` с меткой бренда по центру; меню и содержимое не рисуются, чтобы не было мигания экрана входа. Дольше 3 секунд, под меткой «Проверяем вход…» |
| Нет сессии | Переход на `/login`; адрес запоминается и после входа открывается он же |
| Сессия истекла (ответ `unauthorized`) | Переход на `/login` с сообщением «Сессия закончилась. Войдите снова.» |
| Загрузка названия клиники | Заглушка в бренде (выше); меню работает |
| Ошибка `GET /v1/clinic` | Бренд без названия; меню и содержимое работают. Отдельное сообщение не показываем |
| Пользователь без клиники (`forbidden` или `not_found` на `/v1/clinic`) | Вместо содержимого карточка по центру: «Ваша почта пока не привязана к клинике» / «Напишите нам, мы подключим» и кнопка «Выйти». Меню не показываем |
| Нет сети | Над содержимым полоса `--color-warn-soft` / `--color-warn-ink`: «Нет связи с сервером. Показаны последние загруженные данные.» Пропадает, когда связь вернулась |
| Страница не найдена | «Такой страницы нет» + кнопка «На Рабочий стол» |

## Доступность

- Порядок Tab: ссылка «Перейти к содержимому», пункты меню, «Выйти», затем содержимое.
- Рамка фокуса на меню белая (`--focus-ring-on-dark`), на остальных поверхностях бордовая.
- Активный пункт имеет `aria-current="page"`, кроме цвета выделяется фоном и белым текстом (не только цвет).
- Цели нажатия не меньше 40px (на мобильном 44px).
- `prefers-reduced-motion`: стрелка и экран без анимации.
- Язык документа `lang="ru"`.
