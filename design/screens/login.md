# Экран входа

Вход по почте и паролю через Supabase Auth (`signInWithPassword`). **В прототипе v6 экрана входа нет.** Экран собран из существующих элементов v6 и токенов, нового визуального языка нет; вопросы партнёру записаны в `docs/handoff.md`. Регистрации, сброса пароля, входа через соцсети, ролей и выбора клиники на этапе 0 нет: клиника определяется по токену (`docs/api-contract.md`).

## Структура

```
              ▮  ВетФинанс              метка и название, как в меню (светлый вариант)

   ┌──────────────────────────────────┐
   │ Вход                              │   h1, 26px / 800
   │ Войдите, чтобы увидеть деньги…    │   пояснение, 13,5px, ink-soft
   │                                   │
   │ Почта                             │   подпись
   │ [ name@clinic.ru              ]   │   поле
   │ Пароль                            │
   │ [ ••••••••                    ]   │
   │                                   │
   │ [        Войти               ]    │   основная кнопка
   └──────────────────────────────────┘
        Нет доступа? Его выдаёт команда ВетФинанс.     сноска
```

| Элемент | Источник в v6 | Вид |
| --- | --- | --- |
| Страница | `body`, `--bg-soft` | Фон `--color-bg`, содержимое по центру по горизонтали и вертикали (`min-height: 100vh`) |
| Бренд | `.brand-mark`, `.brand-name` | Метка 40px с логотипом `--color-accent` на `--color-accent-faint`, рядом «ВетФинанс» 18px / 800 цветом `--color-ink`; над карточкой, отступ снизу 24px |
| Карточка | `.card` | Ширина `--auth-card-width` (400px), фон белый, рамка, `--radius-card`, `--shadow-card`, отступы `--card-padding` |
| Заголовок | `.head h1` | «Вход», `--fs-h1`; под ним пояснение `--fs-sm`, `--color-ink-soft`, отступ 3px |
| Подпись поля | `.field span` | 13px, 600, `--color-ink`, отступ снизу 6px |
| Поле | `.inp` | Высота `--control-height` (44px), фон `--color-bg`, рамка 1px `--color-control-border`, `--radius-sm`, отступы 0 13px, текст 14px / 600 (на 390px 16px, чтобы iOS не увеличивал страницу) |
| Основная кнопка | `.act.pri` | На всю ширину, высота 44px, фон `--color-accent-dark`, текст белый 13px / 600 (на 390px 14px), `--radius-sm` |
| Сообщение об ошибке формы | `.warnline` | Блок над кнопкой: фон `--color-bad-soft`, текст `--color-bad`, 13,5px / 600, `--radius-md`, отступы 11px 14px |
| Сноска | `.note` | 12,5px, `--color-ink-soft`, по центру, под карточкой, отступ 16px |

Тексты: заголовок «Вход»; пояснение «Войдите, чтобы увидеть деньги клиники»; подписи «Почта», «Пароль»; кнопка «Войти»; в процессе «Входим…»; сноска «Нет доступа? Его выдаёт команда ВетФинанс.» (формулировку подтвердить, вопрос в handoff).

## Состояния

### Поле ввода

| Состояние | Вид |
| --- | --- |
| Обычное | Рамка `--color-control-border`, фон `--color-bg` |
| Наведение | Рамка `--color-ink-soft` |
| Фокус | Рамка `--focus-ring` (2,5px бордовая, отступ 2px), фон белый |
| Заполнено | Без изменений |
| Ошибка | Рамка 1px `--color-bad` + подпись под полем 12,5px `--color-bad` (текст, не только цвет), `aria-invalid="true"`, `aria-describedby` на подпись |
| Отключено (во время отправки) | Фон `--color-track`, текст `--color-ink-soft`, курсор обычный |

### Кнопка «Войти»

| Состояние | Вид |
| --- | --- |
| Обычное | `--color-accent-dark`, белый текст |
| Наведение | Фон `--color-accent` |
| Фокус | `--focus-ring` |
| Отправка | Текст «Входим…», кнопка неактивна (`disabled`, `aria-busy`), поля заблокированы; повторная отправка невозможна |
| Отключено | Не отключаем до ввода: пустую форму отправить можно, чтобы получить понятную подсказку |

### Экран целиком

| Состояние | Что показываем |
| --- | --- |
| Исходное | Пустая форма; фокус в поле «Почта» |
| Пустые поля | Под полем: «Введите почту» / «Введите пароль»; фокус на первом поле с ошибкой |
| Почта без `@` | «Проверьте почту: похоже, в адресе опечатка» |
| Неверные почта или пароль (Supabase `invalid_credentials`) | В блоке ошибки: «Неверная почта или пароль. Проверьте и попробуйте ещё раз.» Не говорим, что именно неверно. Пароль очищается, фокус в поле «Пароль» |
| Слишком много попыток (429) | «Слишком много попыток. Подождите минуту и попробуйте снова.» |
| Нет связи | «Нет связи с сервером. Проверьте интернет и повторите.» |
| Другая ошибка | «Не получилось войти. Попробуйте ещё раз через минуту.» Текст ошибки Supabase не показываем |
| Сессия закончилась | При переходе с экрана кабинета сверху карточки блок `--color-warn-soft` / `--color-warn-ink`: «Сессия закончилась. Войдите снова.» |
| Почта не привязана к клинике (вход удался, но `GET /v1/clinic` вернул `forbidden` или `not_found`) | Показывается экран «Ваша почта пока не привязана к клинике» из `shell.md` |
| Успех | Переход на запомненный адрес или на Рабочий стол |
| Уже вошёл | При открытии `/login` с живой сессией: сразу на Рабочий стол |

Ошибки не исчезают сами, пока человек не изменил поле или не отправил форму снова. Блок ошибки имеет `role="alert"`.

## Адаптив

| Ширина | Что |
| --- | --- |
| 1280 | Карточка 400px по центру |
| 820 | То же |
| 390 | Карточка на всю ширину минус по 16px с краёв, отступы внутри 20px 18px; бренд над карточкой; поля и кнопка 44px; шрифт полей 16px |

Клавиатура экранная на 390px закрывает низ: форма прокручивается, кнопка «Войти» остаётся достижимой, фиксированного «прилипшего» подвала нет.

## Доступность

- Поля имеют видимые `<label for>`; плейсхолдеры не заменяют подписи.
- Атрибуты: почта `type="email"`, `autocomplete="username"`, `inputmode="email"`, `autocapitalize="none"`, `spellcheck="false"`; пароль `type="password"`, `autocomplete="current-password"`. Менеджеры паролей должны работать.
- Отправка по `Enter` из любого поля.
- Сообщения об ошибках связаны с полями (`aria-describedby`) и объявляются (`role="alert"`).
- Порядок Tab: почта, пароль, «Войти». Ссылок «Забыли пароль» и «Регистрация» нет.
- Контраст: все пары не ниже 4,5:1; рамка поля 3,3:1.
- Страница имеет `<title>`: «Вход · ВетФинанс» и один `<h1>`.
- Цель нажатия не меньше 44px.

## Данные и безопасность

- Почту и пароль отправляем только в Supabase Auth, в наш API они не уходят. Пароль не пишем в журнал, в URL и в хранилище.
- Токен хранит клиент Supabase; в `localStorage` ничего своего не кладём.
- Защита от перебора на стороне Supabase; на экране только текст ошибки.

## Чего нет и почему

| Чего нет | Причина |
| --- | --- |
| Показать пароль (глаз) | В v6 такого элемента нет, не изобретаем; вопрос партнёру |
| «Забыли пароль?», регистрация | Нет в v6 и в задачах этапа 0; вопрос владельцу продукта |
| Вход через Яндекс, Google | Не в MVP |
| Выбор клиники | Одна клиника на пользователя, определяется токеном |
