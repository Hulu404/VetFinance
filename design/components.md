# Каталог компонентов

Этап 0: три компонента для Рабочего стола (разделы 1–3). Этап 1: компоненты для «Транзакций» и «Подключений» (разделы 4–14). Остальные (карточка совета с «Почему?», шкала нормы, полоса структуры цены, календарный день, переключатель) описываются перед этапами, где они нужны. Токены: `design/tokens.css`. Ссылки «v6» ведут в `design/vetfinance-prototip-v6.html`, указан класс CSS или ключ.

Что в v6 нет и собрано из имеющегося (диалог, тост, поле загрузки, полоса сообщения, поле выбора статьи) помечено «нет в v6»; вопрос партнёру записан в `docs/handoff.md`, новых цветов и форм там нет.

Общие правила для всех компонентов:

- Фон, цвет, размеры, радиусы и анимации только из токенов.
- Эмодзи в карточке это значок, он скрыт от скринридера (`aria-hidden`), смысл несёт подпись.
- Состояния описаны одинаково: обычное, наведение, фокус, выбрано/открыто, отключено, загрузка, ошибка, пусто. Если состояние компоненту не нужно, так и записано.
- Цели нажатия на экранах до 820px не меньше 40×40 (в токенах `--touch-min` 44).

## Форматирование чисел (общее для всех компонентов)

Клиент форматирует, но не считает (правило 1 из `CLAUDE.md`). Разбивку из API показываем как пришла, сумму строк с итогом не сверяем.

| `unit` | Вход (API) | Вывод | Правила |
| --- | --- | --- | --- |
| `rub` | `41280000` копеек | `412 800 ₽` | Рубли = копейки / 100 (деление только для показа). Тысячи разделены неразрывным пробелом (U+00A0), перед `₽` тоже неразрывный. Копейки показываем, только если они не нулевые: `412 800,50 ₽` |
| `rub`, отрицательное | `-732000` | `−7 320 ₽` | Настоящий минус U+2212 без пробела; в тёмной подсказке плюс к нему красный цвет, но знак есть всегда |
| `pct` | `15.0` | `15,0%` | Один знак после запятой, запятая, без пробела перед `%` |
| `count` | `154` | `154` | Тысячи разделены неразрывным пробелом |
| `days` | `11` | `11 дней` | Склонение: 1 день, 2–4 дня, 5–20 дней, 21 день |
| нет значения | `null` | `—` | Длинное тире, подпись «нет данных» рядом |

Плюс перед положительным числом ставим только там, где это изменение (рост, дельта): `+15 400 ₽`.

## 1. Карточка показателя (KpiCard)

**Назначение.** Показывает одно число с названием и открывает подсказку `FigureTip` с разбивкой этого числа. Основной «кирпич» Рабочего стола. Источник: v6 `.acc` (карточки счетов) и `.mcard` (карточки месяца), гнездо `data-tip`.

Каждая цифра имеет подсказку: карточка получает один объект `Figure` и передаёт его в `FigureTip`. Без `Figure` (нет данных) число не показывается вообще, карточка в состоянии «пусто».

### Анатомия

```
┌──────────────────────────────┐
│ 💰   ОСТАТОК НА СЧЕТАХ        │   значок · подпись
│      412 800 ₽                │   число
└──────────────────────────────┘
```

| Часть | Вид | Токены |
| --- | --- | --- |
| Поверхность | Белая карточка, рамка 1px | `--color-surface`, `--color-border`, `--radius-card`, `--shadow-card`, `--kpi-padding` |
| Значок (эмодзи) | 29px, `line-height:1`, слева, зазор 14px | декоративный, `aria-hidden` |
| Подпись | 11px, 700, заглавные, `letter-spacing:.07em` | `--fs-2xs`, `--color-ink-soft` (в v6 `ink-faint`) |
| Число | 22px, 800, `letter-spacing:-.02em`, отступ сверху 2px | `--fs-kpi`, `--fw-extrabold`, `--ls-tight`, `--color-ink` |
| Подстрока (вариант «с подстрокой») | 12,5px, 600, отступ сверху 4px | `--fs-xs`, цвет по смыслу: `--color-ok`, `--color-bad` или `--color-ink-soft` |

### Варианты

| Вариант | Где в v6 | Отличия | Этап |
| --- | --- | --- | --- |
| `accent` (главный) | `.acc.hi` | Фон `--gradient-accent`, без рамки, число и значок белые, подпись `--color-on-accent-soft` | 0 |
| `default` | `.acc` | Как в анатомии | 0 |
| `detailed` (с подстрокой) | `.mcard` | Значок 25px, число 23px (`--fs-kpi-lg`), выравнивание по верху, подстрока под числом | 2 (Рабочий стол «Месяц», Транзакции, Склад) |

Подстрока никогда не содержит число, которого нет в `Figure` (например, «+11% к августу» берётся из своего `Figure`, а не считается на клиенте). Если сравнение возвращает API, оно выводится вторым `FigureTip` на подстроке, а не внутри первого.

### Размеры и поведение по ширине

| Ширина | Раскладка |
| --- | --- |
| 1280 | Колонки равной ширины, зазор `--grid-gap`. На этапе 0 две колонки, на этапе 2 три |
| 820 | Две колонки (содержимое 792px) |
| 390 | Одна колонка, карточка на всю ширину; значок 29px, число 22px; текст не переносится по числу (`white-space: nowrap`), подпись при нехватке места переносится на вторую строку |

Минимальная высота 88px во всех состояниях, чтобы загрузка не сдвигала страницу.

### Состояния

| Состояние | Вид и поведение |
| --- | --- |
| Обычное | Как в анатомии. Курсор `help` (как в v6), так как карточка раскрывает подсказку |
| Наведение | Подъём `transform: translateY(-2px)`, `--dur-base`; открывается `FigureTip`. При `prefers-reduced-motion` подъёма нет, вместо него рамка `--color-accent-light` |
| Фокус | Рамка `--focus-ring`, отступ 2px; радиус не меняется. Подсказка открывается так же, как при наведении |
| Открыто (подсказка показана) | `aria-expanded="true"`; рамка `--color-accent-light` (на `accent`-варианте без изменений) |
| Нажатие (касание) | Переключает подсказку (открыть/закрыть) |
| Отключено | У карточки нет |
| Загрузка | Заглушка: подпись (80×11px) и число (140×22px) блоками `--color-track`, радиус 6px, пульс `vf-skeleton` 1,4 с. Значок виден. Карточка не фокусируется. На `accent` заглушки белые с прозрачностью 25% |
| Обновление (данные уже есть) | Заглушки не показываем: остаются прежние цифры, пока идёт запрос в фоне |
| Ошибка | Число заменено на «—», под ним в подстроке «не загрузилось» цветом `--color-bad`. Подсказки нет, карточка не фокусируется. Ошибку всего блока показывает экран (см. `screens/dashboard-stage0.md`), в отдельных карточках она показана только если сломалась одна из них |
| Пусто (нет `Figure` или нет счетов) | Число «—», подстрока `--color-ink-soft` «нет данных» или причина из экрана («счетов пока нет»). Подсказки нет |
| Отрицательное число | Знак «−» и подстрока «ниже нуля» (на `accent`-варианте число остаётся белым, цвета красным не красим: контраст) |

### Доступность

- Если есть подсказка, вся карточка это `<button type="button">` (допустимо `div` с `role="button"` и `tabindex="0"`), который открывает подсказку. Доступное имя: «Остаток на счетах, 412 800 ₽». Подсказка связана через `aria-describedby` (пока открыта).
- Активация с клавиатуры: фокус открывает подсказку, `Enter` и `Space` переключают, `Esc` закрывает.
- В загрузке: контейнер блока `aria-busy="true"`, внутри скрытый текст «Загружаем остаток».
- Число читается целиком в одном элементе, без разбиения на спаны.

### Тексты

Подпись: существительное, до 24 знаков, без глаголов и двоеточия. Этап 0: «Остаток на счетах», «В банке». Подстрока: до 32 знаков, строчными, без точки («ниже нуля», «нет данных»).

### Данные

| Карточка | Поле API | Источник разбивки |
| --- | --- | --- |
| Остаток на счетах | `GET /v1/dashboard` → `balance.total` | `Figure.breakdown` (по счетам: расчётный, касса), `source`, `note` |
| В банке | `balance.bank` | `Figure.breakdown` (по банковским счетам) |

## 2. Подсказка FigureTip

**Назначение.** Раскрывает любое число: из чего оно составлено (`breakdown`), откуда данные (`source`) и пояснение (`note`). Ядро продукта (функция 5). Источник: v6 `#tip`, шаблоны `T[...]` (например `acc_all`, `o_rev`).

### Соответствие `Figure` и вида

Вход компонента: `figure: Figure`, `title: string` (подпись показателя, например «Остаток на счетах»; её даёт карточка, в `Figure` её нет), `emoji?: string`.

```
┌ [Остаток на счетах] ──────────┐   метка = title (стиль .tag из v6)
│ 💰 412 800 ₽                  │   значок + figure.value, формат по figure.unit
│ Расчётный счёт     341 300 ₽  │   строки = figure.breakdown (label, value)
│ Касса клиники       71 500 ₽  │
│ ───────────────────────────── │   разделитель, только если есть строки и пояснение
│ Данные из банка и кассы...    │   figure.note (как пришла, клиент текст не меняет)
│ Источник: [Банк] [Касса]      │   figure.source → метки
└───────────────────────────────┘
```

| Часть | Источник | Вид (токены) |
| --- | --- | --- |
| Метка | `title` | 11px, 700, фон `--color-on-dark-chip`, радиус 6px, отступ 2px 8px, цвет белый |
| Заголовок | `figure.value` + `unit` | 14px (`--fs-base`; в v6 13,5px), 700, белый; значок слева, если передан |
| Строка разбивки | `breakdown[i].label`, `.value`, `.unit` | Название слева `--color-on-dark-sub` 13px, значение справа белое 600, `white-space: nowrap`; между строками 4px сверху и снизу; отрицательное значение `--color-tip-bad`, положительная дельта `--color-tip-good` (со знаком) |
| Разделитель | | 1px `--color-on-dark-line`, отступ 9px |
| Пояснение | `figure.note` | 12,5px (`--fs-xs`), `--color-on-dark-text`, сверху линия и отступ 9px |
| Источник | `figure.source[]` | Строка «Источник:» и метки (как «Метка»); подписи ниже |

Подписи источников (`source`): `bank` → «Банк», `vetmanager` → «Ветменеджер», `manual` → «Внесено вручную», `calc` → «Расчёт», `bot` → «Бот» (появится в очереди 2). Неизвестное значение выводим как есть, ошибки не бросаем.

Блоки скрываются, если данных нет: пустой `breakdown` ничего не рисует (без «разбивки нет»), пустой `note` или `source` тоже. Если нет ни одного, подсказка показывает только заголовок и значение; такой `Figure` для сервиса ошибка, и тестировщик это проверяет (правило 4 из `CLAUDE.md`).

### Размеры

| Параметр | Значение |
| --- | --- |
| Ширина | по содержимому, не больше `--tip-max-width` (335px); на 390px не больше `100vw − 24px` |
| Внутренние отступы | 15px 17px |
| Фон, радиус, тень | `--color-sidebar`, `--radius-lg`, `--shadow-tip` |
| Слой | `--z-tip` (99), рисуется в корне документа (portal), не внутри карточки |
| Высота | не больше 60vh; при превышении внутренний скролл (когда в разбивке много строк) |
| Расстояние до источника | 8px |

### Поведение

Открытие:

| Способ | Правило |
| --- | --- |
| Наведение мыши | Через 80 мс после входа на источник (чтобы не мигала при пролёте курсора) |
| Фокус с клавиатуры | Сразу при `:focus-visible` |
| Касание | Тап на источнике переключает; тап вне подсказки или прокрутка страницы закрывает |

Закрытие: уход мыши с источника и с самой подсказки (через 120 мс, подсказка не пропадает, если курсор перешёл на неё: нужно, чтобы можно было выделить и скопировать цифру), потеря фокуса, `Esc`, повторный тап. Одновременно открыта одна подсказка. Подсказка не закрывает фокус: после `Esc` фокус остаётся на источнике.

Позиция: привязана к источнику, а не к курсору (в v6 следовала за курсором и имела `pointer-events: none`, это ломало работу с клавиатуры и переход на подсказку). Предпочтительно снизу по центру, при нехватке места сверху; по горизонтали сдвигается внутрь окна с отступом 12px.

Анимация: появление `opacity 0→1` и `translateY(5px → 0)`, `--dur-base`; при `prefers-reduced-motion` только прозрачность.

### Состояния

| Состояние | Вид |
| --- | --- |
| Обычное (закрыта) | Не в потоке, не в дереве доступности |
| Открыта | Как в схеме выше |
| Наведение на саму подсказку | Остаётся открытой |
| Фокус | У самой подсказки фокуса нет, он остаётся на источнике |
| Выбрано | Не применяется |
| Отключено | Нет `Figure` → источник не получает подсказку, `cursor` обычный |
| Загрузка | Подсказка не открывается, пока нет `Figure` |
| Ошибка | Не применяется (ошибку показывает карточка) |
| Пусто | Только заголовок и значение (см. выше) |

### Поведение на ширинах

| Ширина | Что |
| --- | --- |
| 1280 | Рядом с карточкой, 335px максимум |
| 820 | То же; открытие по наведению и касанию |
| 390 | Ширина до `100vw − 24px`, горизонтальный отступ 12px; снизу или сверху от карточки; закрывается тапом вне; при появлении не двигает страницу |

### Доступность

- Разметка `role="tooltip"` с `id`; у источника на время показа `aria-describedby="<id>"`. Строки разбивки пишутся как «Название, значение» в порядке DOM (скринридер читает последовательно).
- Доступна с клавиатуры без мыши (фокус, `Esc`), касанием и наведением (требования WCAG 1.4.13: подсказку можно закрыть, навести на неё курсор, она не пропадает сама).
- Цвет не единственный носитель смысла: отрицательные значения имеют знак «−», положительные дельты «+».
- Контраст всех текстов в подсказке не ниже 4,5:1 (см. `tokens.md`).
- Тап вне подсказки не должен вызывать действий под ней (клик «проглатывается»).

### Что в подсказке не делается

- Клиент не пересчитывает и не проверяет сумму строк.
- Клиент не склеивает `note`: текст приходит от backend.
- Нет кнопок и ссылок внутри (подсказка не интерактивна). Если понадобится «Открыть операции», это будет другой компонент.

## 3. Плашка (Pill)

**Назначение.** Короткий статус или метка рядом с названием: источник данных, норма, срок, «скоро». Источник: v6 `.pill` и варианты `.red`, `.grn`, `.vm`, `.gr`, `.tg`.

### Анатомия и размеры

Строчный элемент `inline-block`: текст 11px (`--fs-2xs`), 700, `white-space: nowrap`, отступы 3px 9px, радиус `--radius-xs`. Высота около 22px. Не интерактивна, поэтому правило 40px не применяется. Если плашка станет кнопкой (фильтр), это сегментный переключатель или `Chip`, а не `Pill`.

### Варианты

| Вариант | Фон | Текст | Смысл | Примеры |
| --- | --- | --- | --- | --- |
| `warning` (по умолчанию в v6) | `--color-warn-soft` | `--color-warn-ink` | Внимание, близко к границе | «ниже нормы», «данные устарели» |
| `danger` (`.red`) | `--color-bad-soft` | `--color-bad` | Плохо | «без статьи», «не загрузилось» |
| `success` (`.grn`) | `--color-ok-soft` | `--color-ok-ink` | Хорошо | «в норме», «это вы» |
| `neutral` (`.gr`) | `--color-track` | `--color-ink-soft` | Нет оценки: категория, диапазон нормы | «20–25%» |
| `vetmanager` (`.vm`) | `--color-vm-soft` | `--color-vm-ink` | Источник «Ветменеджер» | «Ветменеджер» |
| `bot` (`.tg`) | `--color-tg-soft` | `--color-tg` | Источник «бот» (очередь 2) | «Бот» |
| `on-dark` (новый, из `.tag` в `#tip`) | `--color-on-dark-chip` | `--color-on-dark` | На тёмном фоне: меню, подсказка | «Скоро», «Банк» |

Правила выбора цвета: зелёный и красный только для оценки «хорошо» и «плохо»; для категорий и источников `neutral`, `vetmanager`, `bot`. Цвет не единственный носитель смысла: в плашке всегда слово («в норме», «выше нормы на 2,4 п.п.»), никогда пустая цветная точка.

### Состояния

| Состояние | Вид |
| --- | --- |
| Обычное | Как в таблице |
| Наведение, фокус, выбрано, нажатие | Нет (плашка статична, в порядок табуляции не входит) |
| Отключено | Нет; «скоро» оформляется вариантом `on-dark` |
| Загрузка | Плашка не показывается (место не резервируется, если она в строке справа от названия) |
| Ошибка | Плашка `danger` с текстом ошибки, если статус относится к объекту («не загрузилось») |
| Пусто | Если текста нет, плашку не рисуем |

### Поведение на ширинах

Размер не меняется. Одна строка (`nowrap`); если плашка не помещается в строку рядом с названием, переносится на следующую целиком. Максимальная длина текста 24 знака; длиннее только в таблицах на 1280, где ширина колонки задана.

### Доступность

- Контраст пар не ниже 4,5:1 (проверено в `tokens.md`).
- Для скринридера текст плашки читается в потоке текста. Плашка рядом с числом должна связываться со значением по смыслу («Норма 20–25%»), а не стоять отдельным словом.
- Смысл не только цветом: слово обязательно.

### Тексты

Строчные буквы, без точки, без восклицаний. Не пугаем: «выше нормы на 2,4 п.п.», а не «опасный перерасход». Сроки пишем числом и единицей: «45 дней».

### Статусы операции и источники (расширение Pill, этап 1)

Новых цветов нет, это таблица соответствия значений API готовым вариантам Pill. Плашка всегда со словом.

| Поле API | Значение | Текст плашки | Вариант | Где показывается |
| --- | --- | --- | --- | --- |
| `status` | `ok` | Плашки нет. Вместо неё в колонке «Статья» плашка с названием статьи (`neutral`) | | «Все» |
| `status` | `check` | без статьи | `danger` (v6 `.pill.red`) | «Все», «На проверку» |
| `status` | `duplicate` | дубль | `warning` | «Все» (строка приглушена: текст `--color-ink-soft`), «Дубли» |
| `kind` | `transfer` | перевод между счетами | `neutral` (в колонке «Статья» вместо статьи) | «Все» |
| `source` | `bank` | Банк | `neutral` (v6 `.pill.gr`) | везде |
| `source` | `vetmanager` | Ветменеджер | `vetmanager` | везде |
| `source` | `manual` | Вручную | `neutral` | везде |
| `source` | `bot` | Бот | `bot` | в MVP не появляется; вариант заведён заранее |

Статья (`category.name`) показывается плашкой `neutral` как в v6. Если у операции `status = ok`, но `category = null` (перевод), см. строку про `transfer`. Зелёный для статуса «ок» не используем: зелёный несёт оценку «хорошо», а «разнесено» это не оценка, а норма. Ряд зелёных плашек в 148 строках шумел бы.

Сокращения (`ВМ`, как в v6) не используем: на мобильном места хватает.

## 5. Поле формы (Field)

**Назначение.** Подпись, элемент ввода, подсказка и сообщение об ошибке. Виды ввода: текст, сумма, дата, список (select), флажок, сегментный переключатель «Расход / Доход» (см. раздел 6). Источник: v6 `.field`, `.inp` (в v6 это макеты без состояний, состояния взяты из `screens/login.md`).

### Анатомия

```
Подпись                      13px, 600, --color-ink, отступ снизу 6px
[ поле                    ]  высота 44px
Подсказка или ошибка         12px, отступ сверху 6px

| Часть | Вид |
| --- | --- |
| Поле | Высота `--control-height`, фон `--color-bg`, рамка 1px `--color-control-border`, `--radius-sm`, отступы 0 13px, текст 14px / 600 (на 390px: 16px, иначе iOS увеличивает страницу) |
| Подпись | Над полем, всегда видимая, связана через `<label for>`. Обязательные поля не помечаем звёздочкой; необязательные добавляют в подпись «(необязательно)» серым |
| Подсказка | `--color-ink-soft`, поясняет формат: «Например, 5 400 или 5 400,50» |
| Ошибка | `--color-bad`, 12px, 600, текст вместо подсказки; `aria-invalid="true"`, `aria-describedby` на сообщение |

Виды:

| Вид | Особенности |
| --- | --- |
| Текст | `<input type="text">`; адрес Ветменеджера: `inputmode="url"`, `autocapitalize="none"`, `spellcheck="false"` |
| Сумма | `<input type="text" inputmode="decimal">`, справа внутри поля «₽» (`--color-ink-soft`, не часть значения). Принимает цифры, пробелы, запятую или точку; разделитель разрядов в поле не навязываем. Преобразование в копейки разбором строки, не через число с плавающей точкой |

| Флажок | Нативный `<input type="checkbox">` 22×22px, `accent-color: var(--color-accent-dark)`, подпись справа 14px, вся строка нажимается; высота строки 44px |
| Пароль, ключ | `type="password"`, `autocomplete="off"`, кнопки «показать» нет (в v6 такого элемента нет, а ключ после сохранения показывать целиком нельзя) |

| Состояние | Вид |
| --- | --- |
| Обычное | Как выше |
| Наведение | Рамка `--color-ink-soft` |
| Фокус | `--focus-ring` (2,5px бордовая, отступ 2px), фон белый |
| Заполнено | Без изменений |
| Выбрано | Для флажка: заливка `--color-accent-dark`, белая галочка |
| Отключено | Фон `--color-track`, текст `--color-ink-soft`, рамка `--color-border`; подпись остаётся читаемой. Причина в подсказке под полем |

| Ошибка | Рамка 1px `--color-bad`, текст ошибки под полем (цвет не единственный носитель). Ошибка пропадает, когда человек изменил поле. ### Доступность

Подпись видимая и связана с полем. Ошибки объявляются: при отправке фокус на первое проблемное поле, сообщение читается через `aria-describedby`. Автозаполнение: адрес `autocomplete="url"` не ставим (это не адрес пользователя), ключ `autocomplete="off"`. Цель нажатия не меньше 44px.

## 6. Вкладки и сегментный переключатель (Tabs, Segmented)

**Назначение.** Один визуальный стиль для двух разных по смыслу вещей. Источник: v6 `.seg` и `.seg button .cnt`.

| Вариант | Смысл | Семантика | Где |
| --- | --- | --- | --- |
| `Tabs` | Переключает содержимое под собой | `role="tablist"`, кнопки `role="tab"`, `aria-selected`, содержимое `role="tabpanel"` с `aria-labelledby` | «Все / На проверку / Дубли / Правила разнесения» |
| `Segmented` | Выбирает значение поля формы | `role="radiogroup"` с подписью, кнопки `role="radio"`, `aria-checked` | «Расход / Доход» в форме операции |

### Вид (общий)

Ряд кнопок, зазор 5px, снизу отступ 16px, переносится на вторую строку (`flex-wrap`). Кнопка: рамка 1px `--color-border`, фон белый, `--radius-sm`, отступы 9px 16px, текст 13,5px (`--fs-sm`), 600, `--color-ink-soft`. Выбранная: фон и рамка `--color-sidebar`, текст белый. Высота 40px; на 820 и уже 44px.

Счётчик (`.cnt`, только у `Tabs`): справа от подписи, отступ 6px, 11px, 800, цвет `--color-accent` (6,4:1 на белом); на выбранной вкладке `#F29BB8` (вариант из v6, 8,6:1 на `--color-sidebar`). Счётчик 0 не показываем. Счётчик входит в доступное имя вкладки: «На проверку, 12». Счётчик это число списка, который открывает сама вкладка, поэтому подсказки у него нет (исключение из правила «у каждой цифры подсказка»: список под вкладкой и есть её разбивка).

### Состояния

| Состояние | Вид |
| --- | --- |
| Обычное | Как выше |
| Наведение | Рамка `--color-accent`, текст `--color-accent-dark` (как `.qb:hover` в v6) |
| Фокус | `--focus-ring`; стрелки влево/вправо перемещают фокус между вкладками (`Tabs` с автоактивацией), `Home` и `End` в начало и конец; в ряд Tab попадает одна вкладка (выбранная) |
| Выбрано | Тёмная заливка + белый текст + `aria-selected="true"` (не только цвет: ещё инверсия контраста и состояние для скринридера) |
| Отключено | Фон `--color-track`, текст `--color-ink-soft`. Вкладок так не отключаем: если данных нет, вкладка открывается и показывает пустое состояние |
| Загрузка | Вкладка доступна, счётчик показывается заглушкой 14×11px `--color-track` до ответа |
| Ошибка | Счётчик не показываем; вкладка работает |
| Пусто | Счётчик скрыт |

### Адаптив

1280 и 820: одна строка, если помещается. 390: перенос на вторую строку, вкладки не сжимаются и не обрезаются; можно в ленту с горизонтальной прокруткой не превращать (v6 переносит). Каждая кнопка 44px.

### Состояние в адресе

Выбранная вкладка хранится в адресе (`?tab=check`), чтобы обновление страницы и кнопка «назад» работали. `Segmented` в адресе не хранится.

## 7. Поле выбора статьи (CategoryField)

**Назначение.** Выбрать статью (категорию) операции из списка статей клиники. Нет в v6 (там «Выбрать категорию» кнопка без самого выбора); собрано из поля, списка `.srow`-подобных строк и подсказки сегмента. Данные: `GET /v1/categories` (запрос уходит один раз на экран, кэшируется).

### Анатомия

Поле (вид «Список» из раздела 5) с ARIA-паттерном combobox: в поле можно печатать, список ниже фильтруется.

```
Статья
[ Аренда и коммуналка              ▾ ]
┌───────────────────────────────────┐
│ ДОХОДЫ                            │  заголовок группы 11px капсом
│ Доход · услуги                    │
│ Продажа товаров                   │
│ ПЕРЕМЕННЫЕ РАСХОДЫ                │
│ Закупка препаратов                │
│ …                                 │
└───────────────────────────────────┘
```

Группы: «Доходы», «Переменные расходы», «Постоянные расходы» (поле `type` из `GET /v1/categories`; точные поля в запросе backend). Для операции-расхода показываются расходные группы, для дохода только «Доходы»: тип операции определяет `kind`. Пункт: высота 44px (на 1280 40px), текст 14px, 500; выбранный отмечен галочкой `✓` справа и `aria-selected`. Список: фон белый, рамка `--color-border`, `--radius-lg`, `--shadow-card`, высота не больше 264px (6 пунктов), дальше скролл; ширина как у поля.

### Состояния

| Состояние | Вид |
| --- | --- |
| Обычное | Поле (раздел 5) с названием выбранной статьи или плейсхолдером «Выберите статью» |
| Наведение (пункт) | Фон `--color-accent-faint` |
| Фокус | Рамка фокуса на поле; активный пункт списка (по стрелкам) фон `--color-accent-soft` + `aria-activedescendant`, фокус остаётся в поле |
| Выбрано | Пункт с галочкой; в поле название статьи |
| Отключено | Как поле. Пока идёт сохранение |
| Загрузка | Поле отключено, плейсхолдер «Загружаем статьи…» |
| Ошибка загрузки | Под полем: «Не получилось загрузить статьи.» + кнопка `text` «Повторить»; сохранить нельзя |
| Пусто (нет статей) | В списке строка серым: «Статей пока нет.» (на практике не бывает: статьи заводит система) |
| Нет совпадений | «Такой статьи нет. Список статей настраивается в разделе Настройки → Категории.» Новую статью из поля создать нельзя |
| Ошибка валидации | «Выберите статью» (рамка `--color-bad` + текст) |

### Поведение

Открытие: клик по полю, `Alt+↓`, ввод символа. Ввод фильтрует по вхождению без учёта регистра и «ё/е». Стрелки двигают активный пункт, `Enter` выбирает, `Esc` закрывает список (диалог при этом не закрывается: первое нажатие `Esc` закрывает список, второе диалог), `Tab` закрывает список и оставляет выбранное. Список не шире диалога и не выходит за экран: на мобильном открывается вверх или вниз, где больше места, и не двигает страницу.

### Доступность

`role="combobox"` на поле, `aria-expanded`, `aria-controls`, `aria-autocomplete="list"`; список `role="listbox"`, группы `role="group"` с `aria-label`, пункты `role="option"`. Количество найденных читается через `aria-live="polite"`: «Найдено 3 статьи». Цель нажатия на пункт 44px на мобильном.

### Данные

| Что | Откуда |
| --- | --- |
| Список статей и группа | `GET /v1/categories` (поля `id`, `name`, `type`; запрос к backend в `docs/handoff.md`) |
| Выбранное значение уходит | `category_id` в `PATCH /v1/transactions/{id}` и `POST /v1/transactions` |

Каждая сумма это `FigureTip` (правило 4 из `CLAUDE.md`): ячейка суммы содержит кнопку, которая открывает подсказку. Заголовок подсказки «Операция», значение `amount`, разбивка и источник из `Transaction.figure` (запрос к backend). Пока backend не отдал `figure`, фолбэк: подсказка из полей операции без вычислений: строки «Дата», «Счёт», «Источник», «Статья», «Как разнесена» (если известно). Фолбэк временный и убирается, когда `figure` приходит.

│ [Доход · услуги]                       │  статья или «без статьи»
│ [ Выбрать статью ]                     │  кнопка, 44px, на всю ширину (только где есть действие)

```

На 820 тот же вид, строка помещается без переноса операции; кнопки действий в одной строке справа от плашки статьи, если места хватает, иначе на всю ширину. Отступы строки 14px 0. Это решение вместо v6, где таблица на узких экранах просто сжималась.

| Выбрано | Нет (массовых действий нет) |
| Отключено | Строка со `status = duplicate` в «Все»: текст `--color-ink-soft`, плашка «дубль», действий нет |
| Загрузка | 6 строк-заглушек: полосы `--color-track` по колонкам (дата 40×13, операция 60% × 14, сумма 80×14), пульс `vf-skeleton`. Шапка колонок видна. `aria-busy="true"`, скрытый текст «Загружаем операции» |
| Загрузка следующей страницы | Под таблицей кнопка «Показать ещё» меняет подпись на «Загружаем…» |
| Обновление | Старые строки остаются, заглушек нет |
| Ошибка | Блок ошибки вместо таблицы (`screens/transactions.md`) |
| Пусто | Блок пустого состояния вместо таблицы; тексты по вкладкам в `screens/transactions.md` |

### Доступность

- Над таблицей `<caption class="sr-only">` («Операции за сентябрь 2026»); колонки `<th scope="col">`. Колонка «Действие» имеет скрытую подпись.
- Для скринридера сумма читается «Минус 5 400 рублей», плашка статьи «Статья: без статьи». Название кнопки действия включает операцию: «Выбрать статью для операции «Такси за анализами»».
- Кнопка суммы с подсказкой: доступное имя «−5 400 ₽, показать из чего состоит».
- Порядок Tab: в строке слева направо; между строками Tab идёт по кнопкам, а не по строкам.
- Цель нажатия на 820 и уже 44px.

## 9. Диалог (Dialog)

**Назначение.** Короткая форма или подтверждение поверх страницы: правка статьи, ручная операция, загрузка выписки, удаление правила. **Нет в v6**: собран из белой карточки `.card`, кнопок и затемнения; других форм не вводим. Вопрос партнёру в `docs/handoff.md`.

### Вид

| Часть | Вид |
| --- | --- |
| Затемнение | `--color-backdrop`, на весь экран, `--z-dialog` |
| Окно | Белое, `--radius-card`, `--shadow-tip`, отступы 24px (`--card-padding` с боков 24px) |
| Ширина | `--dialog-width` 480px; для загрузки выписки `--dialog-width-wide` 540px; по центру, от верха 10vh |
| Высота | Не больше 90vh, содержимое прокручивается внутри, шапка и кнопки остаются на месте |
| Заголовок | `<h2>` 19px (`--fs-xl`), 700, слева; справа кнопка-крестик «Закрыть» 44×44 (значок ✕, `--color-ink-soft`) |
| Подзаголовок | 13px `--color-ink-soft`, под заголовком, при необходимости |
| Кнопки | В конце, справа: `secondary` «Отмена» слева от `primary`; отступ сверху 20px |

На 820 и уже окно превращается в лист снизу: на всю ширину, верхние углы `--radius-card`, нижних нет, отступы 20px 18px, кнопки друг под другом на всю ширину (главная сверху), высота до 92vh. Анимация: появление `opacity` + `translateY(12px → 0)`, `--dur-slow`; при `prefers-reduced-motion` только `opacity`.

### Состояния

| Состояние | Вид |
| --- | --- |
| Открыт | Как выше |
| Сохранение | Кнопки и поля отключены, у главной кнопки «Сохраняем…»; закрыть нельзя, пока запрос идёт |
| Ошибка | Блок над кнопками: фон `--color-bad-soft`, текст `--color-bad`, 13,5px, 600, `--radius-md`, отступы 11px 14px (v6 `.warnline`), `role="alert"`; поля и введённые данные сохраняются |
| Закрытие с несохранёнными данными | `Esc`, крестик или «Отмена» при изменённой форме открывают маленькое подтверждение поверх: «Закрыть без сохранения?» / «Закрыть» (danger) / «Остаться». Если ничего не меняли, закрывается сразу |
| Клик по затемнению | Не закрывает (чтобы не потерять ввод случайным касанием) |

### Доступность

Нативный `<dialog>` с `showModal()` (фокус заперт внутри, остальное неактивно). `aria-labelledby` на заголовок. При открытии фокус на первом поле (для подтверждения на кнопку «Остаться»/безопасную). При закрытии фокус возвращается на кнопку, которая открыла диалог (если её уже нет, например строка исчезла из списка, на заголовок списка). `Esc` закрывает. Прокрутка страницы под диалогом заблокирована. Контраст как у остальных поверхностей.

## 10. Поле загрузки файла и прогресс (FileDrop, ProgressBar)

**Назначение.** Выбрать файл выписки и показать, как идёт загрузка. **Нет в v6**; рамка из `.inp`, дорожка из `.track` / `.fill`, текст из `.note`.

### FileDrop

```
┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┐
  Перетащите выписку сюда
  или  [ Выбрать файл ]
  Формат 1С, файл .txt, до 10 МБ
└ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ┘
```

Пунктирная рамка 1,5px `--color-drop-border`, фон `--color-bg`, `--radius-lg`, отступы 22px, текст по центру: заголовок 14px / 600, подсказка 12px `--color-ink-soft`. Внутри настоящий `<input type="file" accept=".txt">`, скрытый визуально, и `secondary`-кнопка «Выбрать файл», привязанная к нему. Размер «до 10 МБ» подставляется из настроек (по умолчанию 10 МБ; запрос к backend).

| Состояние | Вид |
| --- | --- |
| Обычное | Как выше |
| Наведение / перетаскивание над полем | Рамка `--color-accent`, фон `--color-accent-faint`, текст «Отпустите файл» |
| Фокус | `--focus-ring` вокруг кнопки «Выбрать файл» |
| Выбрано | Вместо схемы: имя файла (14px, 600, обрезка в середине многоточием, полное в `title`), размер («84 КБ»), кнопка `text` «Убрать». Рамка сплошная `--color-border`, фон белый |
| Отключено | Пока файл грузится: фон `--color-track`, кнопки нет |
| Загрузка | Поле заменено строкой с именем файла и `ProgressBar` под ней |
| Ошибка | Рамка 1px `--color-bad`, под полем текст ошибки (список в `screens/transactions.md`); поле остаётся доступным для выбора другого файла |
| Пусто | Исходное |

На 390px: слов «Перетащите сюда» нет (перетаскивание на телефоне не работает), остаются кнопка «Выбрать файл» на всю ширину и строка формата. Проверка на клиенте: расширение и размер; содержимое проверяет backend.

Доступность: клавиатурой работает только кнопка «Выбрать файл» (Enter, Space); перетаскивание это дополнение, не единственный путь. Ошибка связана с полем через `aria-describedby`, объявляется `role="alert"`. Выбранный файл объявляется: «Выбран файл statement.txt, 84 килобайта».

### ProgressBar

Дорожка высотой `--progress-height` на `--color-track`, радиус 6px, заливка `--color-accent`. Рядом текст 13px: этап и процент («Загружаем файл… 63%»). Два режима: определённый (идёт отправка файла, процент от браузера) и неопределённый (сервер разбирает файл: заливка на всю ширину с пульсом `vf-skeleton`, текст «Разбираем операции…», процента нет). Разрыв сети переводит в состояние ошибки. Проценты прогресса это временная подпись процесса, а не показатель, подсказки у неё нет.

`role="progressbar"` с `aria-valuenow` (только в определённом режиме), `aria-valuemin`, `aria-valuemax`, `aria-label` «Загрузка выписки»; смена этапа объявляется через `aria-live="polite"`. При `prefers-reduced-motion` пульса нет, заливка статична.

## 11. Тост (Toast)

**Назначение.** Короткое подтверждение или ошибка после действия, которое не меняет экран очевидным образом. **Нет в v6**; собран в стиле подсказки (тёмная поверхность `--color-sidebar`, белый текст, `--radius-lg`, `--shadow-tip`), чтобы не вводить новый цвет.

### Вид

Ширина `--toast-width` (380px), на 820 и уже: на всю ширину минус по 12px. Отступы 14px 16px, текст 13,5px (`--fs-sm`), 600, белый. Слева значок статуса не используем (эмодзи в тосте нет, смысл словами). Справа кнопка «Закрыть» 44×44 (✕). Под текстом по необходимости ссылка-действие («Посмотреть правило», «Открыть дубли»): 13px, 700, цвет `--color-accent-light` (на `--color-sidebar` 9:1), подчёркнута. Позиция: снизу справа с отступом 24px (на 820 и уже: снизу по центру, отступ 12px, над системной областью). Слой `--z-toast`. Несколько тостов складываются стопкой по 8px, не больше трёх, старые уходят.

| Вид | Когда | Время | Роль |
| --- | --- | --- | --- |
| Успех | Действие выполнено: «Операция добавлена» | 8 секунд | `role="status"` (вежливо) |
| Ошибка | Не получилось и нет места для сообщения в самом экране | Не исчезает, пока не закрыт | `role="alert"` |

Ошибка в тосте отличается словами («Не получилось…»), а не цветом: красной заливки нет (тост тёмный); перед текстом ошибки читается «Ошибка:» скрытым текстом (`sr-only`) и видимое слово «Не получилось».

| Состояние | Вид |
| --- | --- |
| Появление | `opacity` и `translateY(8px → 0)`, `--dur-base`; при `prefers-reduced-motion` только `opacity` |
| Наведение / фокус внутри | Таймер приостановлен |
| Фокус | Ссылка и крестик с `--focus-ring-on-dark` |
| Закрытие | Крестик, `Esc` когда фокус в тосте, истечение времени |
| Отключено, загрузка, пусто | Нет |

Доступность: тост не забирает фокус. Всё важное из тоста дублируется на экране (строка в списке, плашка), потому что тост исчезает (WCAG 2.2.1): тост это подтверждение, не единственное место сообщения. Зона `aria-live` создаётся один раз при загрузке приложения.

## 12. Полоса сообщения (Banner)

**Назначение.** Сообщение над содержимым экрана: данные устарели, ошибка синхронизации, нет связи. Источник: v6 `.warnline`; в оболочке уже описана полоса «Нет связи» (`shell.md`), здесь общий компонент.

| Вариант | Фон | Текст | Когда | Пример |
| --- | --- | --- | --- | --- |
| `warning` | `--color-warn-soft` | `--color-warn-ink` | Данные устарели, нет связи | «Данные обновлены вчера в 04:12 и могли устареть.» |
| `danger` | `--color-bad-soft` | `--color-bad` | Ошибка синхронизации | «Ветменеджер не удалось обновить: ключ не подошёл.» |

Третьего варианта («информация») нет: сообщение без смысла «внимание» или «плохо» полосой не показываем.

Вид: `--radius-md`, отступы 11px 14px, текст 13,5px / 600, ссылка-действие справа той же строкой (13px, 700, подчёркнута, цвет текста полосы); на 820 и уже ссылка переносится на следующую строку слева. Цель нажатия ссылки 44px. Закрыть нельзя: полоса пропадает, когда причина исчезла. `role="status"` для `warning`, `role="alert"` для `danger` при появлении. Состояния наведения (подчёркивание ссылки толще) и фокуса (`--focus-ring`); загрузки и пусто нет.

## 13. Статус подключения (ConnectionStatus)

**Назначение.** Показать, в каком состоянии источник данных. Источник: v6 `.srow` + `.dot` + зелёный текст «обновлено сегодня в 04:12» (экран «Настройки → Ветменеджер»).

Строка: точка 8×8px (`.dot`, в v6 7px) + название 14px / 600 + мета 12px `--color-ink-soft` под ним; справа текст статуса 13px / 600 и, где есть, плашка. Цвет точки и текста дублирует слово.

| Статус | Точка | Текст справа | Плашка |
| --- | --- | --- | --- |
| Не подключено | серая `--color-ink-faint` (v6 `.dot.off`) | «не подключено» `--color-ink-soft` | нет |
| Обновлено | `--color-ok` | «обновлено сегодня в 04:12» цветом `--color-ok` (4,5:1 на белом) | нет |
| Идёт синхронизация | `--color-accent`, пульс `vf-skeleton` | «синхронизация идёт…» `--color-ink-soft` | нет |
| Данные устарели | `--color-warn` | «обновлено 8 сентября в 04:12» `--color-warn-ink` | `warning` «данные устарели» |
| Не удалось обновить | `--color-bad` | «не удалось обновить» `--color-bad` | `danger` «ошибка синхронизации» |
| Обновлено частично | `--color-warn` | «обновлено не всё» `--color-warn-ink` | `warning` «обновлено частично» |

Относительные даты: «сегодня в 04:12», «вчера в 04:12», иначе «8 сентября в 04:12» (год только если не текущий); время в поясе клиники. Состояния наведения, нажатия, выбранного нет (не интерактивно); фокус только у кнопок рядом; загрузка: заглушка вместо текста статуса (110×13px); ошибка загрузки самих статусов: «Не получилось узнать состояние» `--color-ink-soft` + кнопка `text` «Повторить». Доступность: статус текстом, точка `aria-hidden`; смена статуса объявляется (`aria-live="polite"` на тексте статуса).

## 14. Форматирование дат и времени (дополнение к форматированию чисел)

| Вид | Вход (API) | Вывод | Правило |
| --- | --- | --- | --- |
| Дата в таблице | `2026-09-09` | «9 сен» | `Intl.DateTimeFormat('ru-RU', {day:'numeric', month:'short'})`, точку после месяца убираем; год показываем, если он не текущий в поясе клиники |
| Дата в тексте | `2026-09-09` | «9 сентября 2026» | `day: numeric, month: long, year: numeric` |
| Время | `2026-09-09T04:12:00+03:00` | «04:12» | В поясе `clinic.timezone`, не браузера |
| Месяц | `2026-09` | «Сентябрь 2026» | Заглавная первая буква; «за сентябрь» — родительный месяц строчными |
| Размер файла | байты | «84 КБ», «2,1 МБ» | Одна цифра после запятой от МБ |
